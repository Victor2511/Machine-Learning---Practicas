## 🚀 Cómo Ejecutar los Notebooks Localmente
1) Clonar el repositorio:
   git clone [https://github.com/Victor2511/Machine-Learning---Practicas.git](https://github.com/Victor2511/Machine-Learning---Practicas.git)
   cd Machine-Learning---Practicas
2) Crear y activar un entorno virtual con Python 3.10.21:
   conda create -n ml-curso python=3.10.21
   conda activate ml-curso
3) Instalar las dependencias necesarias:
   pip install numpy pandas matplotlib seaborn scikit-learn tensorflow notebook
4) Lanzar Jupyter Notebook:
   jupyter notebook o jupyter lab en caso de haber instalado el mismo en Anaconda Navigator
